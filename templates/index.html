Training Model

Klik tombol untuk memulai proses training dan evaluasi empat model machine learning, yaitu LSTM, Simple RNN, Random Forest, dan XGBoost menggunakan data historis harga Bitcoin periode 2024–2026 yang diperoleh dari Yahoo Finance. Setelah proses training selesai, performa setiap model dibandingkan menggunakan metrik MAE, RMSE, MAPE, dan R². Model dengan performa terbaik digunakan sebagai model utama untuk prediksi harga Bitcoin, sedangkan model lainnya digunakan sebagai pembanding.
